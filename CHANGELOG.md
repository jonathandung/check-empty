# Changelog

All notable changes to this project are and will be documented in this file.

This project uses [Semantic Versioning](https://semver.org) starting from v2.0.0.

## [2.0]

### [2.0.0] - 2026-09-14

Retroactively filled in changelog; exported all outputs from a custom reporter to
workflows using this action; comprehensively implemented more versatile reporters; made
helper `Handler` class public; intersphinx additions; updated Python requirement to
Python 3.8+.

## [1.3]

### [1.3.0] - 2026-09-12

Stabilized the reporter API; refactored symbols into submodules; corrected some
documentation; started exploring archive traversal; updated Python requirement to
Python 3.7+.

## [1.2]

### [1.2.3] - 2026-09-11

Preliminary implementation of the reporter API, which allows for more flexible
and composable output formats.

### [1.2.2] - 2026-09-06

dependencies from an extra to a dependency group.

### [1.2.1] - 2026-09-02

Some refactorings and dependency updates.
